Project Description

Hangman is a word guessing game developed using Python 3.

The computer selects a secret word, and the player guesses the word by entering one letter at a time.

The player gets a maximum of six wrong guesses. The game ends when the player guesses the complete word or reaches six wrong guesses.

To use the random module.

To develop a simple interactive game.
